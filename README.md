# 🍎 Divino Fruts Script

Script avançado para Roblox com funcionalidades de **Aimbot** e **ESP** com interface estilizada **Red-Z Hub**.

## 📋 Recursos

- ⚔️ **Aimbot** - Sistema de mira automática
- 👁️ **ESP** - Visualização de inimigos através de paredes
- 🎨 **Interface Red-Z Hub Style** - Design moderno e intuitivo
- ⚡ **Otimizado** - Código eficiente e rápido
- 🔒 **Compatível com Delta Executor**

## 🚀 Como Usar

1. Abra o **Delta Executor** (ou outro executor Roblox)
2. Execute o seguinte comando:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/alexcersa18-oss/divino-fruts-script/main/Loader.lua"))()
```

3. Aguarde o carregamento do script
4. Aproveite as funcionalidades!

## 📁 Estrutura do Projeto

- `Loader.lua` - Arquivo principal de carregamento
- `main.lua` - Script principal com todas as funcionalidades
- `README.md` - Este arquivo

## ⚙️ Requisitos

- Roblox com suporte a scripts
- Delta Executor ou similar
- Acesso à internet para carregar o script
